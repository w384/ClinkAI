# ClinkAI 非目标（NON-GOALS）

> 显式列出**刻意不做**的事——边界清晰是"小步可验证"的前提。
> 每条都附"替代方案"，避免读者误以为"没做=缺失"。

## 核心非目标

| 不做 | 为什么 | 替代方案 |
|---|---|---|
| **MCP / stdio 外部工具协议** | 引入进程间协议 = 依赖面与攻击面扩大，偏离"零依赖+本地" | `tools-ext`（进程内本地 .mjs）；未来如需要，`integrations/` 下 opt-in 薄集成 |
| **网络工具（web fetch / web search）** | 与"本地+隐私"定位冲突 | 用 `bash` 调本机工具；或用户自写 tools-ext |
| **并行子代理 / 子代理嵌套** | 顺序继承轨迹才可控；并行引入竞态与不可审计 | `delegate` 单个子代理；多任务拆成多个 goal |
| **跨 goal / 跨会话自动记忆** | 隐式状态是调试地狱 | `MEMORY.md`（显式文件，用户可见可编辑）+ `--resume` |
| **API 层微压缩 / 全量压缩 / 压缩熔断** | MVP 规模下归档摘要一次即够 | `ctxBudget` 归档式摘要（`compress.ts`） |
| **GUI / SDK / 多语言绑定** | 扩大维护面 | CLI + JSONL 会话文件（可管道、可脚本） |
| **遥测 / 分析 / 任何外发数据** | 与定位直接冲突（gate 守护） | 无 |
| **包管理器 / 构建步骤** | 零依赖承诺的一部分 | Node 原生执行 `.ts`（Node ≥22） |
| **Windows 之外的平台保证** | 当前开发/测试均在 Windows | 代码只用 `node:` 内置 API，跨平台可行但未承诺 |

## 能力级非目标（各能力文件头部亦有重复声明）

### delegate（`src/capabilities/delegate.ts`）
- 不做并行（子代理顺序执行）
- 不嵌套（子代理只能用 `BUILTIN_TOOLS`，不能再 delegate）
- 不继承父会话自定义工具（固定内置集，边界清晰）
- 不做子代理间的消息传递

### goal（`src/capabilities/goal.ts`）
- 轮次间不并行（轨迹继承要求顺序）
- 不做轮次间上下文压缩（继承完整轨迹；单轮内归档由循环层负责）
- 不跨 goal 记忆（走 MEMORY.md）
- `error/breaker-*` 不自动重试（同上下文重试大概率重蹈覆辙，交回执给用户决策）

### tools-ext（`src/capabilities/tools-ext.ts`）
- 扩展工具不得引入网络调用（网络只留给模型端点）
- 工具间无共享状态（每个 execute 无状态）
- 不支持热重载（进程启动时一次性加载）
- 扩展工具不得遮蔽内置工具（注册期拒绝）

## 判断标准（何时该把"非目标"转正）

- 有**真实用户场景**反复撞到边界（不是想象出来的需求）；
- 能给出**契约测试**（先写测试，再实现）；
- 不破坏已列的差异化不变量（0 运行时依赖 / 默认回环 / 无遥测）；
- 用户显式确认（见 `docs/DESIGN.md` §8 纪律 4）。

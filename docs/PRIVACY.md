# ClinkAI 隐私文档（PRIVACY）

> 承诺：**你的代码、你的上下文、你的机器**。
> 本文列出所有数据流向与边界；每条"不做"都有可执行检查（`test/gate.test.ts`）或代码事实支撑。

## 1. 网络流量：只有一条出网路径

| 项 | 事实 | 守护 |
|---|---|---|
| 唯一网络出口 | `src/model-client.ts` 的 `fetch`（OpenAI 兼容 `/chat/completions`，SSE 流式） | gate：`src` 无 `node:net/dns/tls`、无 `http(s).request` |
| 默认端点 | `http://127.0.0.1:18080/v1`（**回环地址**，不出本机） | gate：默认 baseUrl 必须匹配 `127.0.0.1/localhost` |
| 端点可改 | `--base-url` / `CLINKAI_BASE_URL`（用户显式选择对端，责任归用户） | — |
| 其余组件 | `src` 其他文件**零网络原语** | gate：同上扫描 |

**推论**：ClinkAI 进程产生的唯一外发数据 = 发往你指定的模型端点的 prompt（含工作区文件内容、工具结果、MEMORY.md）。端点若是本机回环，则**没有任何数据离开本机**。

## 2. 零依赖 = 零供应链

- `package.json` `dependencies` **为空**（gate 守护）。
- `src/`、`bin/` 只 import `node:` 内置模块与相对路径本地文件（gate 正则扫描守护）。
- 没有 `node_modules` 运行时、没有安装步骤、没有更新器、没有插件自动下载。
- **推论**：不存在"依赖悄悄升级后开始外发数据"的向量。

## 3. 无遥测、无追踪

- gate 守护：`src` 中不得出现 `telemetry|analytics|tracking|beacon|phone_home` 字样（大小写不敏感）。
- 没有崩溃上报、没有使用统计、没有匿名指纹。
- 失败信息只写本地：会话 JSONL（`meta` 事件）与终端。

## 4. 本地数据存储清单

| 数据 | 位置 | 谁可见 | 保留策略 |
|---|---|---|---|
| 会话文件（完整轨迹：任务/助手正文/工具调用/参数/结果/诊断） | `~/.clinkai/sessions/*.jsonl` 或 `CLINKAI_SESSIONS` | 仅本机（文件权限由 OS 决定） | append-only；用户可随意删除 |
| 工作区文件 | 用户指定 `--workspace` | 用户 | 用户 |
| MEMORY.md | 工作区根目录 | 用户 | 用户（显式编辑） |
| 截断的长输出全文 | 会话文件 `meta: tool-output-truncated` 事件 | 用户 | 与会话同生命周期 |
| eval 结果 | `eval/results.json` | 用户 | 用户 |

**ClinkAI 不写工作区以外的任何文件**（`~/.clinkai/sessions` 除外，且可经 env 重定向）。

## 5. 进程与执行边界

| 能力 | 执行边界 | 备注 |
|---|---|---|
| `bash` 工具 | 本机进程（`powershell`/`cmd`，策略白名单） | 非 TTY 下非白名单自动拒绝；工作区外路径需串行确认 |
| `delegate` 子代理 | **同进程**（不启动新进程、不开新网络出口） | 只多一次对同一模型端点的调用 |
| `goal` 续跑 | 同进程、同端点 | 只多轮调用 |
| `tools-ext` | 同进程执行**用户自己写的 JS** | 责任边界：代码是用户的、机器是用户的；ClinkAI 不审计其内部行为（建议不写网络调用，见 NON-GOALS） |
| 压缩/摘要 | 同进程，经模型端点 | 摘要内容同样只发往你配置的端点 |

## 6. 模型侧注意（不在 ClinkAI 控制范围，如实告知）

- 若你把 `--base-url` 指向**远程** API（非回环），则 prompt 内容会发送到该远端——这是你的显式选择，隐私边界由该服务的数据政策决定。
- 本地模型（llama.cpp/Ollama 等）默认监听回环，ClinkAI 的默认配置与此对齐。
- 提示词中会包含：系统提示词、工作区文件内容、工具输出、MEMORY.md 内容。请据此决定端点选择。

## 7. 审计与自证

- `node test/run-tests.ts` → 运行 gate 不变量（零依赖/回环默认/无网络原语/无遥测字样）。
- 会话 JSONL 是全量轨迹：每次工具调用的参数、结果、耗时、授权结果都在里面，可逐行审计。
- `--doctor` 打印实际生效的端点与模型（核对是否回环）。

## 8. 已知边界（不隐瞒）

1. `tools-ext` 模块是用户代码，ClinkAI 不约束其内部（技术上可 `fetch`）——这是信任边界内的用户自负责。
2. `bash` 工具执行的是本机 shell 命令，其行为不受 ClinkAI 审计（只约束启动白名单与工作区围栏）。
3. 模型本身的权重/推理在本地（llama.cpp），但**模型输出**可能包含你输入的任何内容——不要把机密放进工作区再交给不可信的端点。
